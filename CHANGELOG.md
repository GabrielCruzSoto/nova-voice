## 0.1.0

### Added
- Initial local voice-assisted agentic desktop orchestrator for Linux.
- Hybrid local desktop UI with reactive orb, chat timeline, and IPC security gatekeeper.
- Offline voice pipeline with wake-word detection, Silero VAD, faster-whisper STT, and Piper/Kokoro TTS.
